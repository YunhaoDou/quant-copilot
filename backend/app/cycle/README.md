# 情绪周期与龙头监控

入口为个人投资系统 `/invest?view=cycle`，复用现有 Next.js、Recharts 和 Python 环境。

## 本地运行

在 backend 目录使用已有虚拟环境：

```sh
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
.venv/bin/pytest tests/cycle -q
```

另一个终端进入 frontend：

```sh
npm run dev
```

默认使用统一主后端8000端口，需运行本机PostgreSQL与Redis。只运行情绪研究模块时也可启动`app.cycle.api:app`于8001端口，并为前端设置`NEXT_PUBLIC_CYCLE_API_URL=http://localhost:8001`；该独立模式不依赖数据库与Redis，真实行情仍需要外网，模拟模式不需要。

## 配置与数据源

`config.yaml` 使用合法 YAML 1.2 的 JSON 子集格式，只使用标准库解析，请保持双引号及 JSON 语法。每次请求重新读取，修改后在界面刷新。默认真实源（兼容标识`akshare`）使用腾讯公开报价/分钟接口和东方财富涨停、跌停、炸板、行业板块接口，直接复用其上游协议，不依赖AkShare的全市场慢查询。`mock` 固定种子生成120个工作日及18只虚构股票；不代表任何真实证券。`csv` 读取 `backend/data/cycle/daily.csv` 和 `intraday.csv`。真实接口异常字段留空，不会替换为模拟数据。

日线必需字段以 providers.py 中 MockDataProvider 输出为准，代码按字符串读取；`available_at` 必须带时区，日线为收盘可用快照，价格单位元、涨幅单位百分数、成交量单位股、成交额单位元，市场成交额单位亿元。CSV需提供完整市场覆盖及每个交易日连续报价；历史成员变更由输入快照表达。当前不支持自动处理复权、退市及缺失交易日，请导入前校验。分时字段为 time、available_at、symbol、name、price、volume、amount。

## 规则定义

新低比较当前市场最低点与此前N个完整样本日的市场低点，历史不足返回未知。板块启动使用等权成分股涨幅、收盘涨停家数、最早首封时间三个条件；不声称盘中在该时间已经满足全部条件。龙头按连板高度、首封时间、封单成交额比、炸板次数排序，代码作为最后稳定排序键。炸板率分母是收盘涨停或存在炸板记录的股票数；封板率是收盘涨停数除以该分母。

状态优先级：退潮、冰点、回补、分歧、启动、加速、修复、待确认。回补目前使用全样本平均涨幅较前日恢复、跌停未增加及前日分歧条件，尚不是板块逐一确认。轮动仅人工记录；洗盘、出货不作为已知资金意图。完整分时止跌、缺口回补及回封尚未自动识别。配置中对应阈值为后续接口预留，尚未参与自动信号。

## 事件研究与成交模拟

事件研究选信号日排名第一候选，统计信号收盘到未来N日收盘收益，不扣成本。尾部历史不足显示空值，不计入正收益比例、均值及中位数。同日相关样本不能当作独立证据。

交易模拟单仓、顺序使用现金；信号后下一样本交易日尝试开盘买入，开盘涨停或停牌不成交；按配置仓位及整手取整。买入后N个交易日的开盘尝试卖出，至少隔一个交易日；开盘跌停、停牌或缺报价则推迟。费用包含买入成本、卖出成本及双边滑点。权益按每日收盘标记，计算组合峰谷最大回撤；尾部持仓保留未平仓。事件期限与交易持有期限起点不同，因此两区收益不可直接比较。日线保守假设无法还原排队或真实可成交性。

## 假设与限制

工作日演示日历未排除法定休市；模拟分时为演示插值，不参与信号及成交计算。人工阶段覆盖保存原因、原自动阶段、时间，只存浏览器，不改自动历史与回测。模拟/CSV收盘模式信号15:00才可得，使用as_of截断。真实模式30秒轮询、25秒缓存，分别显示指数报价时间、本机获取时间和数据延迟；股票池只有行情日，无秒级时间戳，因此延迟未知。非交易时段保留最新报价，超过配置年龄标记过期。历史快照以本机观测时间存入`backend/data/cycle/live.sqlite`，不回填未观测历史。真实回测因缺少完整历史板块成员与涨停池暂不展示收益。规则版本随输出保留，但还没有历史配置版本仓库。

## 全项目行情与账户边界

`/market/quotes`提供批量A股及场内基金真实报价；`/market/history/{symbol}`提供最近最多约640根前复权日线，不足年限不会补造。盘中当日未完成日线不进入历史回测；历史取数长度由供应商限制。观察池使用真实现价和动态PE，股息率与质量仍标记人工研究。个股研究、仓位情景、决策记录、模拟账户均有证券报价参考；四策略回测基于真实历史但不完整模拟A股可成交性。

同花顺、中国银河证券、中信建投证券的资金和持仓不属于公开行情。驾驶舱支持CSV/制表符导出文件在浏览器本地预览、导入，代码/名称/数量/成本列必须明确；有数量的持仓用真实行情估算市值。无券商官方授权不连接交易客户端，不收集密码，不提供委托或撤单桥接。账户总资产和资金余额仍依券商快照维护。导入两个券商分别替换各自快照，不删除另一券商或手工记录。

用于研究与复盘，不连接券商，不自动交易，不承诺收益。历史统计不代表未来，模拟数据统计不能评价战法有效性。

## 红利看板与双项目入口

主项目入口为`http://localhost:3000/invest?view=dividends`。`GET /dividends`读取进度及最近成功结果，`POST /dividends/scan`启动后台全市场扫描，重复提交不会创建并发任务。数据缓存位于`backend/data/cycle/dividends.sqlite`，不会提交Git。

初筛使用东方财富全A股报价和过去12年已实施分红，逐页校验总数及代码唯一性。近365天税前派现按每10股派现除以10计算，送转引起每股口径歧义的股票暂时排除。初筛后最多对配置数量的候选核验腾讯前复权日线，每类选出最多8只；该范围不等同于全市场最优。分类评分沿用迁入项目的息率、位置、连续派息及价格稳定性权重45/25/15/15，不代表派息可持续性或估值结论。

分类、行业、低位筛选、股票详情、研究卡片及PNG导出均在网页完成。前90只候选另做30秒报价刷新，其余保留扫描时点；评分仍对应上次完整扫描。PNG导出当前筛选结果的前8条。真实源失败显示错误及旧缓存状态，不回退虚构候选。

另一目录`/Users/douyunhao/Code/quant-copilot`保留Streamlit入口，运行`./.venv/bin/streamlit run app.py --server.port 8501`。其中红利页嵌入主项目真实看板，需要3000前端与8000后端同时运行。原终端分析仍使用Yahoo Finance，不应与A股主系统的腾讯/东方财富来源混同；规则回退及模型观点不属于真实行情事实。

## 真实历史回放

真实模式日期控件已启用，仅读取本机实际采集的快照，回放期间暂停当前行情轮询。选择尚未采集日期时显示空状态和可用日期，不拿今天行情填补历史。新快照同时保存分时及数据来源元信息，早期缺少这些字段的快照明确标记不可用。返回当前按钮恢复实时采集。

日线使用腾讯`newfqkline/get`公开接口，已完成日线按`live_daily_cache_seconds`缓存6小时，收盘前后及跨自然日分别取数，避免重复扫描高频请求上游。全市场扫描默认并发数降为2。上游仍可能限流或变更协议，失败时停止更新并保留标注时间的上次成功数据。

## 券商自动读取的当前限制

用户当前使用手机同花顺，没有Windows/QMT。尚未取得并验证银河或中信建投在此环境下的官方只读账户接口，因此本项目没有实现自动持仓、资金或盈亏同步。公开行情真实接入与券商账户授权是两件事；本地文件导入不代表自动同步已完成。不保存交易密码，不绕过客户端访问限制。
