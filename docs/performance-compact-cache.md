# 大快照重复解析修复

日期：2026-11-14。

## 根因与修改

完整文档缓存96MiB预算保持不变。四份快照解析对象合计约85.5MiB，而同时保留的原始JSON字符串约49.5MiB，合计约135MiB，导致交替查询时LRU反复淘汰与重新解析；不是缩小母池能够解决的问题。

文档缓存改为保留完整解析对象和64字符SHA-256指纹，去掉重复原始字符串。每次到期仍读取真实源内容并计算指纹；内容变化即重新解析，原快照版本仍取相同指纹前24字符。TTL、数据范围、字段、排序、模型规则不变。同长度修改也可识别。上线后四份文档同时保留，约85.5MiB，低于原96MiB预算。
