# 系统化模拟盘协议(pre-committed)

> 目的:用一个**前向、可复现**的模拟盘,客观判断"某个系统化策略是否值得投入真钱"。
> 关键约束:**判据在开跑前锁定,结果出来后不许改**。这是为了防止事后合理化。
> 创建日期:2026-07-15 · 起始日:见 `sim_equity` 首行 · 计划一阶段复盘:开跑满 1 个月

---

## 1. 设计

- **4 个策略并行**,各一个独立模拟账户,互不干扰:
  - `sim-sma_crossover`(SMA 10/30 交叉)
  - `sim-rsi_reversion`(RSI 14,30/70)
  - `sim-momentum`(20 日时序动量)
  - `sim-bollinger_reversion`(布林带 20, 2σ 回归)
- **基准**:`sim-benchmark-spy` —— 第 0 天满仓买入 SPY 并持有到底。
- **标的池**:AAPL, MSFT, NVDA, GOOGL, AMZN, META, TSLA(等权,每标的分到 `本金 / 7` 的美元额度)。
- **本金**:每个账户相同,默认 $1,000(应设为你真打算实盘投入的金额,以保证仓位感真实)。
- **执行**:每个交易日收盘后跑一次 `scripts/run_sim_day.py`——
  - 按**截至当日**的价格算每个策略"该多/该空"(仅用已发生的 bar,无未来函数);
  - flat→long 翻转时买入该标的的美元额度;long→flat 翻转时清仓;
  - 记录当日每个账户权益到 `sim_equity`。

## 2. 成功判据(锁定,一阶段满 1 个月复盘时套用)

某策略要被判为"值得考虑实盘",**必须同时满足**:

1. **跑赢基准**:该策略总收益 > SPY 买入持有总收益(即 `vs_spy_pct > 0`),扣除已计的 0.1% 手续费后。
   —— 跑不赢指数,不如直接买 SPY,策略无意义。
2. **回撤可接受**:期间最大回撤不劣于 SPY 的最大回撤太多(阈值:不超过 SPY 回撤 + 5 个百分点)。
3. **样本不算太薄**:期间成交 ≥ 8 笔。低于此,结果基本是噪声,**判为"数据不足",不予结论**。
4. **不是靠一笔运气**:剔除贡献最大的单笔盈亏后,仍跑赢 SPY。

## 3. 诚实声明(局限)

- **1 个月样本极小**。即使某策略满足全部判据,也**只说明"值得继续观察"**,不等于"稳赚"。
  正式实盘前建议至少累计 **3 个月**前向数据。一阶段(1 个月)只做初筛,不做终审。
- **执行简化**:信号由日线收盘价推导,成交按"最新收盘价"撮合,存在约 1 个 bar 的同日信号/成交简化;
  真实实盘会有滑点、盘中波动、成交价差异。因此模拟收益是**乐观上界**。
- **无再平衡漂移控制**:等权额度在开仓时按固定美元切分,后续不追加/不再平衡。
- **幸存者/选择偏差**:标的池是当下的大盘科技股;这本身是一种事后选择,换一批标的结论可能不同。
- **过拟合警告**:这 4 个策略的参数是常见默认值,未在本模拟期外调优;若月末去"挑参数最好的"再实盘,
  就是把这套前向测试重新变成了过拟合。**要实盘就用未经二次调优的那套。**

## 4. 运行

```bash
cd backend && source .venv/bin/activate       # 需要 backend/.env(DB/Redis/DeepSeek)
python -m scripts.init_sim 1000               # 一次性:建账户 + 拉数据 + 第 0 天
python -m scripts.run_sim_day                 # 每个交易日收盘后跑一次
```

自动化(可选):用 macOS `launchd` 每个工作日 17:30(美东收盘后)触发 `run_sim_day`。
